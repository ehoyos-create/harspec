Demo Shop

Intentionally vulnerable target for harspec. Localhost only.

  • GET /api/products?page=1&limit=2
  • POST /api/auth/login
  • POST /api/cart/items — trusts the price you send
  • POST /api/checkout — trusts the total you send
  • GET /api/users/1 — no ownership check
  • GET /api/debug/env — leaks configuration
